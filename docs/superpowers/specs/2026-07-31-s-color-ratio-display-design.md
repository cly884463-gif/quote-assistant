# 高浓度 S 系列色浆配比显示设计

## 目标

依据《7月19日和中源中国建筑美学色卡色浆配比表_整理后.xlsx》，在高浓度 S 系列色浆的颜色规格选择项后同时显示两种配比，并让已选产品和最终报价清单保留配比信息。

## 设计

- 复用现有 `GN-S-SJ` 产品数据中的 `remark` 配比字段，不重复录入价格或颜色数据。
- 下拉选项显示原规格后追加 `配比(g:g)` 和 `配比(g:ml)` 两项。
- 选择后在卡片下方显示完整配比。
- 最终报价清单中的产品名称追加所选颜色的完整配比。
- 其他产品和原有价格不变。

## 验收标准

1. 96 个 S 系列颜色均同时包含两种配比。
2. S001 等颜色下拉选项可直接看到两种配比。
3. 切换颜色后卡片配比同步更新。
4. 报价图片和表格中的产品名称保留所选配比。
